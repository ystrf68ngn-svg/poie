# poie 0.9.0 预览版

一起思考，无尽创造。首次 GitHub 发行，提供多模型群聊、可停止的讨论、用户批准的协作、模型切换、联网资料、技能和长期记忆。

| 安装包 | 系统 |
| --- | --- |
| `poie-0.9.0-mac-arm64.dmg` | macOS 13+，Apple Silicon |
| `poie-0.9.0-mac-x64.dmg` | macOS 13+，Intel |
| `poie-0.9.0-win-x64.exe` | Windows 10/11，x64 |

Mac 打开 DMG 后将 poie 拖入应用程序；Windows 双击安装。无需 Node.js、Python、终端或 ChatGPT 账号。填写自己的 API 地址和密钥即可，本机 Codex / Claude Code 账号是可选连接。

Mac 使用临时签名，尚未 Apple 公证；Windows 暂无发布者签名，系统可能提示未知开发者。Apple Silicon Mac 已实际运行，Intel Mac 与 Windows 尚未在对应设备运行验收。

`SHA256SUMS.txt` 提供三个安装包校验值。GitHub 的 Source code 仅为源码，开发者需要 Node.js；不是双击安装包。

本次修复自报完成就被标记成功的问题；必要数据缺失时停止依赖任务。完整 CSV 沿协作链传递，支持保存并生成图表与 PDF，旧错误完成状态会重新检查，保留原始对话。

95 项自动测试、TypeScript 和本地构建通过。真实行情与真实 Codex 做过针对性验证；完整界面验收使用模拟模型、真实行情和真实 PDF。范围见 [CHANGELOG](../../CHANGELOG.md)。

源码采用 MIT，第三方组件和模型商标保留原有权利。不要将 API Key、聊天备份或账号信息上传到 GitHub。
