# poie · AI 群聊

在你自己的电脑上运行的 AI 群聊，提供 Windows / macOS 桌面版和源码浏览器版，**不需要 ChatGPT，也不要求登录任何统一平台**。用户决定使用哪些 API、本机账号、群主、角色和技能。

## 桌面版：下载后安装即可

不需要自己安装 Node.js、Python，不需要打开终端，也不需要 GPT 账号。

- **Mac Apple Silicon（M1/M2/M3/M4 等）**：打开 `poie-0.9.0-mac-arm64.dmg`，把「poie」拖入「应用程序」，双击启动。
- **Mac Intel**：使用 `poie-0.9.0-mac-x64.dmg`，安装方法相同。
- **Windows 10/11 x64**：双击 `poie-0.9.0-win-x64.exe`，按安装向导完成。桌面和开始菜单都有「poie」入口。

API 用户打开应用，在「模型连接」填地址、密钥并选择模型即可，无需安装插件或拥有 Codex / Claude 账号。「桌面设置」默认折叠可选能力；使用订阅账号时展开对应项，点击「准备账号连接」→「登录账号」，在官方网页完成授权。已有本机 Codex / Claude Code 登录可以直接检测使用。

本地文本记忆、导入导出、项目技能直接可用。可选的 Hy-Memory 语义检索在「桌面设置」一键准备，应用自动下载专用 Python 和记忆引擎，不修改系统 Python；用户仍需提供自己的 Embedding 服务。下载需要能访问对应官方服务。

安装包位于 `releases/desktop/`。当前是测试发行包，Mac 使用临时签名，尚未 Apple 公证；Windows 尚无发布者签名。系统可能提示未知开发者。正式公开发布应配置自己的签名证书与 Apple 公证，应用不会更改系统安全设置。

### 桌面数据位置

- macOS：`~/Library/Application Support/Tongpin/`
- Windows：`%APPDATA%/Tongpin/`
- 「桌面设置 → 打开应用数据文件夹」可直接查看。聊天与角色在应用的浏览器存储中；技能、记忆、向量索引在 `project/`；可选账号组件在 `tools/`。
- 「在此电脑记住 API 和 Embedding 密钥」默认关闭。选择开启后使用系统加密保存为 `connections.encrypted`；关闭会删除磁盘上的密钥。账号登录继续由官方组件管理，不复制账号凭据。
- 覆盖安装新版保留数据；Windows 卸载也不自动删除应用数据。升级前可导出群聊和记忆。迁移系统时不要将加密密钥文件当作可跨电脑使用的备份。
- 原浏览器版与桌面版的数据位置不同；可用记忆导入导出迁移长期记忆，旧群聊仍可在原浏览器中查看和导出。

### 源码 / 浏览器版（开发者可选）

源码运行才需要 Node.js **22.18+ 或 24**。`npm install` 后 `npm run local`，或使用原有 `启动poie.command` / `启动poie.cmd`，打开 `http://127.0.0.1:4318/`。这不是桌面安装包的使用步骤。

桌面后端随应用启动，随机回环端口只接受应用私有会话；页面使用固定本地来源，重启不丢聊天。正常使用不需要后台终端或 Sites 托管页面。

## 连接模型

### 任意 API / 中转站

在「模型连接」选择预设或「自定义 / 中转站」，粘贴服务商链接并填写自己的 **API Key、接口格式**，点击「读取模型」。支持 OpenAI Chat Completions 兼容格式和 Anthropic Messages 格式。连接名称、模型厂商和成员职责互不绑定。

「服务网址」接受域名、首页、常见控制台链接、带 `/v1` 等前缀的地址，以及完整 `/chat/completions`、`/messages`、`/models` 或 `/responses` 链接；省略 `https://` 也可以。点击「读取模型」后，应用只在原域名下通过只读模型列表请求识别常见路径，并保存验证成功的连接地址，聊天随后沿用它。自定义版本前缀会保留，不会重复添加 `/v1`。认证失败、限流和重定向会明确报错，不会继续遍历或把密钥转发到其他域名。含密钥或查询参数的链接不接受；没有模型列表接口或使用特殊路径的服务仍可填写其文档中的 API 地址与模型 ID。DeepSeek、千问、Kimi 等可以独立使用，不需配置 OpenAI。首次默认群主为 DeepSeek；已有群聊不改变。

模型列表按服务返回；如中转站没有列表接口，可以手动填写它提供的模型 ID。测试按钮实际发送 hello；错误与不兼容参数会原样按安全范围显示，不制造成功状态。输入框内随时切换连接、模型、思考强度，下一条消息生效。

### 本机 Codex / Claude Code 账号（可选）

桌面版使用「桌面设置」一键准备组件和登录，无需以下命令。源码浏览器版先按对应厂商官方指南安装 CLI，在「模型连接」选择「登录 / 切换账号」，会打开官方 CLI 的登录窗口。自行完成登录后，点「检测连接」。也可手动运行：

```sh
codex login
claude auth login
```

- Codex：使用本机 Codex 的 ChatGPT 登录，通过 `codex exec` 对话；无需 OpenAI API Key。模型目录和思考能力来自 `model/list`，目录并不保证所有模型都在套餐中可用。
- Claude Code：使用 `claude auth status` 确认订阅登录（`claude.ai` 或 `oauth_token`），通过 `claude -p` 对话。沿用用户级 CLI 账号配置，不加载项目配置。Console/API-key 登录请改用 API 连接。模型下拉提供官方 CLI 的 Sonnet / Opus / Haiku 别名；实际模型、权限和额度由 CLI 与套餐决定。
- 不复制或传输 CLI 登录凭据，不抓取其他应用的 Cookie。终端继承的厂商 API Key 会从账号适配器子进程中移除。
- 每轮传入当前群聊上下文、职责、启用的技能及授权记忆；隔离工作目录，禁用工具、MCP 和 hooks，不会让聊天模型操作你的电脑。
- 可用 `TONGPIN_CODEX_BIN` / `TONGPIN_CLAUDE_BIN` 指定 CLI 可执行文件。Linux 的登录按钮使用 `x-terminal-emulator`；没有时可直接运行上面的登录命令。
- 本机账号的实际用量、可用模型、超额计费和限制，以相应厂商套餐为准。poie不会将订阅伪装成免费的通用 API。

## 用量与授权

「用量信息」默认不授权、不查询、不记录。逐个连接同意后，可手动刷新余额/额度，之后的聊天保存供应商实际返回的 Token 数。

- Codex：通过官方 `account/rateLimits/read` 查询额度窗口、已用百分比和重置时间。
- DeepSeek 官方端点：通过 `/user/balance` 查询真实余额。不会拿官方密钥去查询一个中转站。
- Claude Code：显示授权之后调用实际返回的 Token，提供官方用量页入口；没有可用的通用订阅余额接口时明确显示不可查询。
- 其他 API：记录实际 Token（服务支持时）；不把 Token 折算成臆测费用，不虚构账号剩余额度。缺失值显示为未提供。

授权可撤回，撤回会停止查询/记录并清除该连接在此浏览器保存的统计。修改 API 地址、接口格式或密钥会撤销原授权。无自动轮询；账号用量仅在点击刷新时读取。最多保存最近 2000 条本浏览器调用记录。

## 群聊与成果

- 发 hello 即可自然接话；@成员或 @所有人自由交流。任何模型都能成为群主并修改职责。
- 普通聊天明确绑定本轮用户消息，历史摘要、旧任务和其他成员的回复仅作为背景。即使 @所有人，后回复的成员仍收到相同的当前用户输入；只有用户要求继续才接续旧工作。
- 仅主动选择「分工协作」时生成方案；批准后才执行，最多 6 项任务，可停止。
- 群聊右上角「… → 删除群聊」，确认后删除消息、方案和群内成果，停止进行中的回复。可通过提示撤销；刷新后撤销入口失效。删除最后一个群后显示创建入口，不会偷偷重建旧群。手动保存到记忆库的内容独立管理。
- HTML/SVG 代码块自动变为成果卡片，支持隔离预览、查看源码、运行/停止和下载；其他代码可下载。沙箱禁止访问群聊页面、密钥和外部网络。Python、编译工程、桌面软件与视频渲染需要额外运行环境。

### 联网协作与简洁展示（0.8.0）

输入框提供「自动联网 / 始终联网 / 不联网」。默认按当前提问判断；财报、最新信息、公开网址和明确搜索要求会触发检索，普通问候不会搜索。联网由 poie 提供，不要求模型厂商自带搜索工具或另填搜索 API Key；Codex、Claude Code 账号及兼容 API 的群成员共用本轮资料。

- 模型先提取必要的公开检索词，平台通过 DuckDuckGo / Bing 公开搜索，再读取原网页及其中实际链接的投资者关系、业绩页面和 PDF。只向搜索引擎发送检索词，不发送整段聊天或 API 密钥；公开网页请求不携带账号登录态。代理返回合成 IP 时，使用 Cloudflare 公共 DNS 核验公开地址。
- 在「分工协作」中检索后制定方案，用户批准后再次获取本轮资料，按方案顺序执行，上一位的完整交付会传给下一位，避免制图或报告成员在数据尚未完成时抢先回答；最后由群主汇总。来源可展开，显示原始链接、读取状态、获取时间和可确认的发布时间；报告导出保留来源。获取时间不等于报告发布时间，模型必须区分财务期间、币种、单位和口径。
- 聊天仅显示简短的检索、处理、汇总状态；不逐字展示内部推理。成员长交付默认折叠，最终结论先简短显示，「查看完整结果」及「成果」保留详细正文。停止会取消搜索、PDF 读取、模型请求和后续任务；已经完成的交付保留。
- 这是公开网页检索与正文节选，不是完整浏览器或实时行情服务。每轮最多 3 个检索词、3 个直接链接，最多读取 6 个候选页面、2 个站内目录和 2 份链接 PDF；PDF 每份不超过 8 MB、100 页，向模型提供相关页面节选。扫描件、登录墙、验证码、受限制网站和依赖脚本的正文可能无法读取，会显示失败或仅有搜索摘要，不伪造结果。
- 「不联网」或消息明确要求不用搜索时只分析已有资料。生成检索词会消耗所选模型额度；已授权用量统计时标记为「检索准备」。托管的旧网站没有此本地研究服务，需要使用更新后的桌面版或本机源码浏览器版。

### 结构化交付检查与行情数据（0.9.0）

成员返回消息后，平台分别记录「已交付 / 待确认 / 受阻」。内部回执只说明成员自报状态，平台还会检查本类任务的实际条件：行情必须有足量数值、同日时间戳和数据来源；制图必须有图表文件；PDF 必须已经由桌面渲染器写成真实文件。股票名单、搜索摘要、未运行脚本、报告模板和可打印 HTML 都不能单独视为这些任务已完成。上游受阻时停止调用后续任务，再由群主如实汇总；用户仍有最终验收权。

- **沪深 A 股行情**：股价/行情任务直接读取腾讯财经公开行情快照，每批 1–100 只。未指定代码时采用明确标注的默认 100 只分层样本，不表示全市场、指数成分或排名。指定六位代码时读取该清单；美股、港股、历史任意日期行情不由这个适配器代替。源接口未承诺长期兼容，失败、停牌缺值、混合日期、缺失或超过 7 天的数据会明确标注，不能假装完成。
- **数值校验**：检查代码、价格、涨跌幅、日期、重复和缺失。源接口部分股票以股、部分以手返回成交量；平台通过成交额与当日价格范围核验单位后统一为手，无法确认则不计为有效行。以源数据时间为准，周末查询不会把旧快照写成当日交易。
- **共享与保存**：本轮完整 CSV 通过独立资料块传给所有成员，数据集 ID、行数、日期和实际文件随任务交接。群内保存结构化原始行，切换模型、重启后仍可下载；说「沿用刚才的数据继续分析」会重新给模型完整数据，避免只留下“采集完成”一句话。导出群聊会去重附上完整 CSV。需要新快照时明确说重新采集。
- **图表**：平台从原始行实际生成完整树状图，面积使用已核验的成交量、颜色使用涨跌幅，模型负责核对与解释；不凭空补行业、市值或未提供的字段。SVG 可预览和下载。
- **PDF**：桌面版将报告正文/内联 HTML 及上游 SVG 在隔离渲染器中生成实际 PDF。聊天直接提供「保存 PDF」，无需额外软件或手动打印。生成中可停止；写入成功才显示已生成。文件位于应用数据 `project/deliverables/`，覆盖升级会保留；CSV、图表及 PDF 应按需单独保存，Markdown 导出不内嵌 PDF 二进制。源码浏览器版仍不自动生成 PDF。
- **旧状态修复**：旧版本把“成员已回复”当成完成。重新打开时保留全部原文，明确无数据/受阻的任务改为受阻，其他未核实旧交付改为待确认。旧失败报告不会被自动重跑。

### 自由讨论

在输入框选择「自由讨论」，输入话题后发送。至少需要两位已连接的群成员，按成员顺序轮流发言；每一位会看到前一位已完成的发言，使用自己的连接、模型与思考设置。默认 3 轮，可选 6 轮、10 轮或「直到我喊停」。每轮每位成员发言一次，会消耗各自模型的额度；自由讨论不会自动批准计划或执行任务。

点击「停止讨论」，或直接发送 `停止`、`停一下`、`暂停`、`结束讨论`、`stop` 等指令，平台在本地立即终止当前请求和后续轮次，不等待模型理解或回复。已完成的发言保留，未完成发言标为停止，迟到的返回不写回聊天。供应商已处理的请求可能仍产生用量。

发送新问题会先停止讨论，再正常回答这条新消息；切换群聊、退出应用也会结束自动讨论，重新打开不会自行恢复。成员出错时停止整轮讨论并显示原因，不自动重试或继续调用下一位。`@所有人` 仍然只是让已连接成员各回复一次，持续交流需主动开启「自由讨论」。

## 项目级 Skill 与记忆

「技能与记忆」连接项目底层服务，不依赖当前聊天模型。

### 记忆迁移与保存

- 聊天中发送 `/记住 具体内容`；或在记忆面板编辑、保存；模型消息旁可选择「保存到记忆库」。
- 支持poie JSON、Hy-Memory 列表/检索 JSON、ChatGPT/Claude 聊天导出、Codex/Claude Code JSONL、Markdown/TXT。先预览后导入，重复内容去重。不是把聊天重新灌入当前群；导入后进入持久记忆库。
- 导入只写入本机。默认不扫描其他应用历史，不自动保存全部对话，不读取任何登录凭据。
- 勾选「允许当前群使用记忆」后，检索相关内容并发送给所选模型；切换厂商继续使用同一记忆。历史记忆是参考数据，当前用户要求优先。可随时编辑、删除、导出。
- 默认用本地文本匹配召回，不需要 Python、Embedding Key 或 GPT。单文件最多 600 KB / 300 条，单工作空间最多 2000 条，每条最多 6000 字符。
- 每轮从记忆库召回最多 6 条相关内容，合计约 6500 字符；不是把整个记忆库发给模型。该库与下面的群聊上下文摘要分别保存。

### 群聊上下文压缩

从 0.6.0 起，长群聊不再直接截取最后 32 条消息或尾部 48000 字符。每轮回复前检查未整理的有效消息；超过 24 条或约 32000 字符时，使用当前回复模型整理较早的记录，之后发送「接续摘要 + 固定要求 + 近期原文」。同一个群的成员共享摘要，换模型、刷新或重启后继续使用。

- **保留内容**：最初目标、用户要求与最新修正、决定、工作进度及验证情况、待办、成果引用、未决问题。分工方案的完整任务要求参与整理，当前任务状态每轮单独提供；成员声称完成不等于实际验收通过。
- **近期原文**：自动整理以保留最近约 12 条、16000 字符为目标。长记录按最多 18000 字符一批连续处理，已整理部分留下位置标记，不从中间漏掉内容。单条新资料仍受所选模型窗口和请求大小限制，超长时明确提示拆分。
- **摘要**：最多 6000 字符，每次将前一份有效摘要与新记录合并；按本轮问题额外找回最多 3 条相关历史原文节选。摘要属于参考数据，当前用户要求优先。
- **固定要求**：输入框下方「上下文」可填写最多 4000 字符的关键要求，每轮完整发送；用户消息旁的图钉可直接固定该条要求。摘要可能遗漏细节，必须持续遵守的约束建议固定。
- **操作与失败恢复**：面板可查看摘要、进度、开关自动整理或点击「立即整理」。每批成功即保存，失败或取消不会覆盖上一份有效摘要；本轮暂停回复并显示原因，不悄悄丢掉旧记录。单次最多整理 6 批，积压更长时保存进度并提示继续整理。同轮多成员不会重复重试失败的整理请求。
- **保存与用量**：压缩不删除原始聊天，原文仍可查看、导出。摘要与固定要求跟随群聊保存在本地；总历史容量仍受设备和浏览器存储限制。整理会消耗所选模型的额外额度；已授权记录用量时，在用量列表单独标记「上下文整理」，不额外查询账号额度。

这些字符阈值是应用的整理策略，不是模型 Token 窗口；实际输入输出上限仍由所选模型或中转服务决定。上下文压缩提高长任务的连续性，不等于无限记忆或保证每个细节永不遗忘。

### Hy-Memory

[腾讯混元 Hy-Memory](https://github.com/Tencent-Hunyuan/Hy-Memory) 是记忆引擎与迁移工具集合，不是直接可安装的 SKILL.md 包。poie内置 `project-skills/hy-memory/SKILL.md` 适配技能，并将官方引擎安装到**应用独立 Python 环境**。桌面版在界面一键准备；以下命令仅用于源码开发：

```sh
# Python 3.11–3.13
npm run memory:install
```

在「Hy-Memory 引擎」提供自己的 OpenAI 兼容 **Embedding 请求网址、模型、维度和 API Key**，同意发送记忆内容后建立索引。调用真实 `HyMemoryClient.from_config(mode="lite")` 的 `add()` / `search()`。不需要 OpenAI 账号；聊天模型与 Embedding 供应商独立。DeepSeek 聊天 API 本身不能代替一个未提供的 Embedding 接口。

未配置、索引过期或服务失败时，明确提示并使用本地文本检索，不冒充 Hy-Memory 成功。记忆修改后旧索引失效；需要重建。引擎固定安装 `hy-memory==2.0.4` 和 `qdrant-client==1.20.0`，采用 Qdrant 本地向量持久化，无需另起数据库服务或下载 FastEmbed 模型。上游采用 Apache-2.0，安装包保留其许可证。这里提供的是导出文件迁移与 lite 检索；没有启用 MemHub 的全盘历史扫描或 Hy-Memory pro/ultra 的自动认知加工。

### 安装其他技能

聊天中发送 `/skill https://github.com/作者/仓库/tree/main/skills/技能名`，或“安装这个 skill：链接”。也可在「项目技能」粘贴链接。

先预览来源、固定提交版本、SKILL.md 与文件列表，确认后安装在 `.tongpin/skills`；再勾选「本群启用」，下条消息会载入说明与有限参考文件。适用于 API、Codex 和 Claude Code。没有 SKILL.md 的普通代码仓库不能冒充技能安装。当前支持提示和参考型技能，脚本只保存、不自动执行；需要 shell/浏览器等工具的技能不会获得这些权限。不会改动个人 Codex/Claude 的技能目录。

## 浏览器源码版的数据与备份

- 聊天、成员、角色、非敏感连接配置和授权后的 Token 统计：当前浏览器的 localStorage。
- API 密钥、Embedding 密钥：当前标签页 sessionStorage；刷新保留，关闭/恢复标签页行为取决于浏览器。清空输入框可删除。
- 项目技能、记忆、Hy-Memory 引擎与索引：项目 `.tongpin/`，已被 Git 忽略。工作空间记忆按随机 ID 隔离，不上传到 Sites 源码或独立发布包。
- 本机与云端网址的浏览器数据分别保存；通过群聊导出和记忆导出备份。迁移电脑前同时备份需要的浏览器导出和项目数据。
- 独立运行包由固定文件白名单生成，包含静态页面、Node 服务和 zod 运行依赖，不包含个人数据、密钥、CLI 账号、Git 元数据或 Sites 登录模块。
